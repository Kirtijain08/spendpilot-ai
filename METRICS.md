# North Star Metric

## Completed Audits Per Week

This is the best metric because:
- it measures real engagement
- users only complete audits if they see value
- completed audits directly generate leads

The product is not a daily-use SaaS tool.

It is a high-intent conversion tool.

---

# Input Metrics

## 1. Landing Page Conversion Rate
Visitors → audit starts

Measures:
- headline quality
- positioning
- trust

---

## 2. Audit Completion Rate
Started audits → completed audits

Measures:
- UX quality
- friction
- loading speed

---

## 3. Consultation Request Rate
Completed audits → booked consultations

Measures:
- business value
- recommendation quality
- lead quality

---

# First Instrumentation

Would track:
- CTA clicks
- audit starts
- audit completions
- share link usage
- consultation button clicks

Likely tools:
- PostHog
- Plausible
- Vercel Analytics

---

# Pivot Threshold

If after 1,000 visitors:
- audit completion rate is below 15%
OR
- consultation conversion is below 3%

then positioning or target audience likely needs adjustment.

At that point:
- messaging
- onboarding
- pricing assumptions
would need reevaluation.
